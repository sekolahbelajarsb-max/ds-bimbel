# Ds Bimbel V45

## Fokus
Perbaikan dan penyempurnaan Profil Siswa.

### Perubahan
- Profil siswa menampilkan identitas lengkap.
- Alamat, jenis kelamin, sekolah, jenjang, kelas, paket, hari, dan pukul ditampilkan terpisah.
- Ringkasan jadwal, absensi, pembayaran, dan tunggakan.
- Tombol Edit Data langsung dari halaman profil.
- Tombol WhatsApp langsung ke nomor wali/siswa.
- Riwayat jadwal, absensi, dan tagihan ditampilkan dalam tabel.
- Tombol Kembali dari profil diperbaiki agar kembali ke Data Siswa.
- Tetap kompatibel dengan mode database online dan mode lokal.
