# Ds Bimbel V34 — HP, Laptop & Online Ready

V34 melanjutkan V31 tanpa mengulang desain. Paket ini dibuat agar website dapat digunakan dari laptop/PC dan diakses HP melalui jaringan Wi-Fi yang sama, serta siap dideploy online.

### Login lokal
- Username: `admin`
- Password: `admin123`

### Jalankan
- Windows: `START-WINDOWS.bat`
- Mac/Linux: `START-LINUX-MAC.sh`
- Manual: `npm install` lalu `npm start`

### Alamat
- Laptop: `http://localhost:3000`
- HP satu Wi-Fi: `http://IP-LAPTOP:3000`
- Online: gunakan `render.yaml` + PostgreSQL.

### Catatan keamanan
Untuk website publik, jangan gunakan password demo. Atur `ADMIN_USERNAME` dan `ADMIN_PASSWORD` di environment hosting.
