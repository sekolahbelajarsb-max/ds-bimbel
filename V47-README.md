# Ds Bimbel V47

V47 melanjutkan V46 dengan fokus komunikasi siswa/orang tua.

## Perubahan
- Profil siswa memiliki panel Komunikasi WhatsApp.
- Nomor WhatsApp orang tua/wali menjadi tujuan utama jika tersedia.
- Template siap pakai: Sapaan, Info Jadwal, Kehadiran, dan Pembayaran.
- Pesan dibuka di WhatsApp untuk diperiksa admin sebelum dikirim.
- Tetap kompatibel dengan Supabase dan struktur V46.

## Deploy
Upload seluruh isi paket ke repository GitHub yang sama lalu tunggu deployment Vercel selesai.
