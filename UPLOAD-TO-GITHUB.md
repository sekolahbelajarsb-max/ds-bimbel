# Cara memasukkan V35 ke GitHub

1. Ekstrak `Ds_Bimbel_V35.zip`.
2. Masuk ke folder hasil ekstrak.
3. Buat repository kosong di GitHub.
4. Upload semua isi folder V35 ke root repository.
5. Pastikan `render.yaml` berada di root.
6. Jangan upload file `.env` atau password produksi.
7. Setelah selesai, buka Render → New → Blueprint → pilih repository tersebut.
